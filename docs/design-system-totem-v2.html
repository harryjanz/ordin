Princípios herdados de BK + McDonald's
🎯
1 cor de ação por tela
BK usa só laranja, MC usa só vermelho. Roxo é o único CTA em evidência. Teal é informativo, nunca concorre.
📐
Touch targets ≥ 82 px
W3C: mínimo 20mm na tela. Em 21" (~104 PPI) equivale a ~82 px. Gap mínimo de 21 px entre alvos.
🔤
Lexend como display
Substituto open-source de Flame (BK) e Speedee (MC). Alta legibilidade em telas touchscreen.

Uso: ações secundárias, navegação, edição.

Tokens CSS

Copie e cole no :root do seu projeto. Dark é ativado via [data-theme="dark"] no html.

/* ═══════════════════════════════════════════
   DESIGN SYSTEM — TOTEM FAST FOOD v2
   Light padrão · dark via [data-theme="dark"]
═══════════════════════════════════════════ */

:root {
  /* — Marca (imutáveis entre temas) — */
  --roxo:           #9900ff;
  --roxo-hover:     #7a00cc;
  --roxo-subtle:    rgba(153,0,255,0.12);
  --roxo-glow:      0 4px 20px rgba(153,0,255,0.35);
  --teal:           #33cccc;
  --teal-dark:      #1a9999;
  --teal-subtle:    rgba(51,204,204,0.15);

  /* — Semânticos — */
  --color-success:  #198737;
  --color-error:    #ff4d6d;
  --color-err-bg:   rgba(255,77,109,0.10);

  /* — LIGHT THEME (padrão) — */
  --bg:             #DFE8ED;   /* background geral */
  --surface:        #ffffff;   /* cards, drawers, modais */
  --header:         #ffffff;   /* header, barra de categorias */
  --border:         rgba(153,0,255,0.18);
  --border-m:       rgba(0,0,0,0.08);      /* bordas neutras */
  --text:           #1d1434;   /* texto principal */
  --muted:          rgba(29,20,52,0.45);   /* texto secundário */
  --btn:            #9900ff;   /* fundo dos CTAs primários */
  --btn-text:       #ffffff;   /* texto dos botões primários */
  --num-bg:         rgba(153,0,255,0.10);  /* inputs numéricos */
  --price-color:    #1a9999;   /* teal escuro no light */
  --card-sh:        0 2px 12px rgba(153,0,255,0.10);

  /* — Tipografia — */
  --font-d: 'Lexend', sans-serif;   /* headings, botões, preços */
  --font-b: 'Inter', sans-serif;    /* corpo de texto */

  /* — Escala de fonte (totem 21") — */
  --text-h1:    42px;   /* instrução principal por tela */
  --text-h2:    26px;   /* nome de categoria */
  --text-h3:    20px;   /* nome de produto */
  --text-price: 28px;   /* preço em destaque */
  --text-cta:   20px;   /* label de botão CTA */
  --text-body:  16px;   /* descrições */
  --text-label: 14px;   /* rótulos de campo */
  --text-small: 12px;   /* badges */

  /* — Espaçamento — */
  --s-xs: 8px;  --s-sm: 12px;  --s-md: 16px;
  --s-lg: 24px; --s-xl: 32px;  --s-2xl: 48px;

  /* — Bordas — */
  --r-sm: 8px; --r-md: 12px; --r-lg: 16px;
  --r-xl: 24px; --r-pill: 999px;

  /* — Touch targets (totem) — */
  --touch-min:  82px;    /* W3C 20mm em tela 21" */
  --touch-add:  52px;    /* botão circular "+" */
  --touch-cta:  120px;   /* largura mínima CTA principal */
  --touch-gap:  21px;    /* espaço mínimo entre alvos */
}

/* — DARK THEME — */
[data-theme="dark"] {
  --bg:          #0e0b1a;
  --surface:     #1d1434;
  --header:      #1d1434;
  --border:      rgba(153,0,255,0.22);
  --border-m:    rgba(255,255,255,0.07);
  --text:        #DFE8ED;
  --muted:       rgba(223,232,237,0.45);
  --num-bg:      rgba(153,0,255,0.12);
  --price-color: #33cccc;   /* teal bright no dark */
  --card-sh:     0 2px 16px rgba(153,0,255,0.20);
  /* roxo, btn, teal — sem alteração entre temas */
}
