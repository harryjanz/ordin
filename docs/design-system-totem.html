Botões e ações

Todos os variantes de botão com tamanhos calibrados para toque em totem. Mínimo de 48×48 px; CTAs principais acima de 120 px de largura.

🔥 Burger King — Botões

CTA primário — Fundo laranja, texto preto, fonte Lexend bold. Raio pill. Uso: "Adicionar", "Finalizar", "Confirmar".

CTA secundário — Outline laranja. Uso: "Ver pedido", "Editar".

Botão destrutivo — Fundo vermelho. Uso: "Remover item", "Cancelar".

Botão "+" para adicionar item ao card — circular, 56×56 px.

56×56 px · border-radius 50%
🍟 McDonald's — Botões

CTA primário — Fundo vermelho, texto branco. Uso: "Adicionar", "Finalizar".

CTA secundário — Fundo amarelo, texto preto. Uso: "Ver pedido", upsell.

Tokens CSS

Copie o bloco de variáveis e cole no :root do seu projeto. Escolha o tema BK ou MC, ou crie um híbrido.

🔥 Tema Burger King — variáveis CSS
:root {
  /* === CORES PRIMÁRIAS === */
  --color-primary:        #FF8732;  /* Flaming Orange — CTA principal */
  --color-primary-hover:  #FFAA00;  /* Melty Yellow — hover state */
  --color-accent:         #D62300;  /* Fiery Red — destrutivo/urgência */
  --color-success:        #198737;  /* Crunchy Green */
  --color-text-on-primary:#0E0C0A;  /* texto sobre botão laranja */

  /* === TEXTO === */
  --color-text-primary:   #F5EBDC;  /* Sesame — texto principal */
  --color-text-secondary: #C4A882;  /* texto secundário */
  --color-text-muted:     #7A6554;  /* placeholders e labels */

  /* === SUPERFÍCIES === */
  --color-bg:             #0E0C0A;  /* background da tela */
  --color-surface:        #1A1612;  /* header e áreas elevadas */
  --color-card:           #251E18;  /* fundo de cards e modais */
  --color-border:         #3D3028;  /* bordas e dividers */

  /* === TIPOGRAFIA === */
  --font-display: 'Lexend', sans-serif;  /* headings, botões, preços */
  --font-body:    'Inter', sans-serif;   /* corpo de texto */

  /* === ESCALA DE FONTES (totem 21") === */
  --text-h1:     42px;   /* instrução principal por tela */
  --text-h2:     26px;   /* nome de categoria */
  --text-h3:     20px;   /* nome de produto destaque */
  --text-price:  28px;   /* preço em destaque */
  --text-cta:    20px;   /* label de botão CTA */
  --text-body:   16px;   /* descrições */
  --text-label:  14px;   /* labels de campo */
  --text-small:  12px;   /* badges e metadados */

  /* === ESPAÇAMENTO === */
  --space-xs:    8px;
  --space-sm:    12px;
  --space-md:    16px;
  --space-lg:    24px;
  --space-xl:    32px;
  --space-2xl:   48px;

  /* === BORDAS === */
  --radius-sm:   8px;
  --radius-md:   12px;
  --radius-lg:   16px;
  --radius-xl:   24px;
  --radius-pill: 999px;

  /* === TOUCH TARGETS (totem) === */
  --touch-min:        82px;    /* mínimo W3C em 21" (20mm) */
  --touch-cta:        56px;    /* altura mínima de botões primários */
  --touch-cta-main:   120px;   /* largura mínima de CTA principal */
  --touch-gap:        21px;    /* espaço mínimo entre alvos */
}
